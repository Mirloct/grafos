# Fuentes validadas

> Registro histórico de investigación. La matriz vigente, con enlaces primarios y alcance de verificación, está en `outputs/documentacion_proyecto.html`, sección Fuentes y ACFE. Las entradas de esta tabla sin enlace ni evidencia de consulta no deben tratarse como fuentes validadas.

| Fuente | Aplicación | Decisión |
|---|---|---|
| FATF Recommendations | enfoque basado en riesgo y transparencia | usar como marco AML/CFT |
| FinCEN Advisory | indicadores de money mule y múltiples señales | usar como tipologías, no como prueba |
| FBI Money Mules | funnel accounts, recepción y redistribución | usar para features de intermediación |
| ACFE/COSO Fraud Risk Management Guide | gobierno, evaluación, controles, investigación y monitoreo | usar para gobernanza del visor |
| ACFE Anti-Fraud Data Analytics Tests | pruebas analíticas antifraude | adaptar a relaciones, concentración y anomalías |
| Carnegie Mellon Graph Mining | centralidad, comunidades, anomalías | usar como soporte técnico |
| INCIBE | casos de fraude y preservación de evidencias | usar como contexto de fraude |
| JPMorgan | uso industrial de graph analytics para conectar pagos | usar como evidencia de aplicabilidad industrial |

## Límites de las fuentes solicitadas

No se verificó en esta revisión una metodología operacional reproducible de CIA, MI6, Department of War, PayPal o Palantir aplicable a estos cuatro campos. Esto describe el alcance de la investigación, no afirma que esas publicaciones no existan. No se atribuyen técnicas a esas instituciones sin documentación primaria verificable.
